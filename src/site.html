About

A bench is where a thing is built and measured before anyone else sees it

Smart-home hardware, self-hosted software, and the network underneath

Bench is where the work gets written down. The name is the literal one — a bench is where a thing is built, measured, and found wanting before anyone else sees it, and that is the part worth publishing.

The work itself is one flat and everything in it: wall switches rewired around ESP32s, blinds that pull their own chain through a printed gearbox, a mirror with a dashboard behind the glass, a Raspberry Pi that routes the internet connection, and an office desktop that became a Proxmox server. Software holds it together — Home Assistant, Docker, and a self-built CMS serving the page you are reading.

The recurring design principle is that no device depends on the rest of the house to do its job. Every ESPHome board carries a local fallback binding in its own firmware, so losing the server costs the automations but not the lights.

A specification that does not say what it assumes is not a specification. It is a description of one run.

How this is set

Two sans-serifs: Inter for display and body, Plus Jakarta Sans for headings. Four accent colours used systematically — cyan for software, magenta for hardware, green for machine learning, orange for writing. Projects without photographs fall back to hand-drawn SVG line plates, so an image slot is never empty.
